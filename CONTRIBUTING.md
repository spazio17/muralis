Thank you for wanting to help. Muralis is **source available**, not open source: anyone may read the
code, use it, change it for themselves and send changes back, under the Fair Core License in
`LICENSE.md`. Nobody may sell Muralis or a product made from it, or remove or work around the Pro
lock, not even for their own use. Each version becomes Apache 2.0 two years after its release.

## How

1. Open an issue first for anything larger than a small fix, so we agree on the shape before code.
2. Fork the repository, make your change on a branch, and open a pull request against `main`.
3. Build and test as the README says (`scripts/test-host.sh`, `scripts/build-app.sh`); the CI
   build must pass.
4. Write the pull request's title as what the code will do; it becomes a line in the release notes.
